# ArabicGamesTranslator

مترجم ترجمات الألعاب إلى العربية على Windows وAndroid. مبني على Sefflex/GameTranslator (AGPL-3.0-only)، مع قارئ Xbox عبر Remote Play وخيارات Google بدون مفتاح، Gemini، DeepL، والنماذج المحلية QuickMT/Jisr/HY-MT على الكمبيوتر.

## التنزيل والتحديث
نزّل حزمة Windows من [Releases](https://github.com/Tariq-220/ArabicGamesTranslator/releases/latest)، وفك الضغط وشغّل Install.cmd مرة واحدة. التطبيق يفحص الإصدارات ويحمّل الجديد تلقائيًا خارج جلسة اللعب. ثبّت التحديث من زر التطبيق عند الانتهاء. مفاتيح API تبقى مشفرة في مجلد بيانات مستخدم Windows ولا تُرفع للمستودع.

## النشر التلقائي
غيّر رقم الإصدار في release/version.json إلى إصدار جديد ثم ادفعه إلى main. GitHub Actions يبني Windows ويختبره وينشر حزمة الإصدار تلقائيًا باستخدام GITHUB_TOKEN الخاص بالوظيفة. لا تضع مفاتيح API أو PAT أو سجلات اللعب في الملفات. الإصدارات المنشورة لا تُستبدل.

## حدود النسخة
الربط الحالي عبر Remote Play؛ لا يوجد ادعاء باتصال Xbox أصلي مدمج. QuickMT يعمل على الكمبيوتر حاليًا وليس داخل Android. أداء ودقة المحركات يختلفان. خاصية حساس القرب على Android تجريبية وتعتمد على الجهاز. أجزاء التحديث والتنزيل مختبرة ببروتوكولات وملفات بديلة؛ الاختبار المادي للكونسول وTV مطلوب.

## المصدر والتراخيص
[المشروع الأصلي](https://gitlab.com/sefflex/GameTranslator)، AGPL-3.0-only. يحتفظ المصدر بحقوق المؤلف والإشعارات. النماذج والمكتبات المرفقة لها تراخيص مستقلة موضحة في NOTICE وlocal-engine. المصدر الموافق للإصدارات داخل حزم التنزيل أيضًا.
