# Google TV 0.3.14 — استعادة عمر جلسة HDMI القديم

- الاحتفاظ بجلسة HDMI وTvView عند انتقال الواجهة للخلفية، كما في المسار القديم؛ لا تُفك الجلسة إلا بإيقاف العرض صراحة أو إنهاء النشاط.
- معالجة تغيّر إعداد العرض واللون داخل النشاط نفسه بدل إعادة إنشاء واجهة التطبيق.
- استعادة ترتيب تهيئة الصوت قبل فتح المدخل، دون طلب تركيز صوت جديد عند كل إشعار جاهزية صورة.
- زر نسخ تقرير العرض يسجل أحداث الواجهة والجلسة محليًا، دون رمز الربط أو عنوان الشبكة.
- لا يوجد وضع HDR خارجي أو إطلاق لتطبيق HDMI آخر أو استعادة تلقائية متكررة للمدخل.
- اختبارات انتقالات Android لا تعادل اختبارًا فعليًا على شاشة المستخدم. الجوال وويندوز دون تغيير.
