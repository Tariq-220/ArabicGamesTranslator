# Google TV / TCL 0.3.12 — إصلاح حلقة HDMI

- يفتح التطبيق على لوحة التحكم حتى مع وجود إعداد التشغيل التلقائي القديم.
- الربط واستقبال الترجمة لا يشغّلان HDMI. اضغط «عرض اللعبة» يدويًا فقط عندما تريد ذلك.
- الرجوع من Home أو إعادة فتح التطبيق لا يعيدان HDMI تلقائيًا.
- زر «إيقاف عرض HDMI والرجوع للإعدادات» يلغي استعادة الإشارة المعلقة.
- الجوال 0.4.14 كما هو؛ لا حاجة لتحديث الجوال أو ويندوز لهذا الإصلاح.
- اختبارات محاكاة؛ لا يضيف الإصدار عرض HDMI خارج التطبيق أو وضع HDR أصليًا تجريبيًا.
