# Windows 0.4.30 — إصلاح إعادة قراءة الحوار المتلاشي

- فحص سجل 0.4.29: 562 حدثًا، 408 QuickMT و154 DeepL؛ 41 حدث ازدحام. النص الإنجليزي المقروء نفسه يتفتت ويتغيّر قبل وصوله للمحركين.
- إبقاء الجملة الكاملة عند قراءة مقدمتها مع كلمة أخيرة مقصوصة خلال 1.2 ثانية، دون دمج جملة مختلفة أو رد قصير مستقل ينتهي بعلامة ترقيم.
- تمرير القراءة المحفوظة إلى حالة الترجمة بدل الخروج المبكر، حتى تبقى إعادة المحاولة وحالة السطر تعملان.
- تفضيل قراءة الصورة الأصلية عندما تكون سليمة بنيويًا، بدل فوز قناع اللون الأبيض لمجرد أنه أنتج حروفًا أكثر. يبقى القناع احتياطيًا للصورة الفارغة أو المتضررة.
- لا تغييرات في الواجهة، المفاتيح، النماذج، HDMI أو تطبيق الشاشة. اختبارات جديدة مستمدة من القراءات الناقصة في السجل. لا يضمن ذلك صحة كل حوار ولا يعادل تجربة فعلية على جهاز المستخدم.
