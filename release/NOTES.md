# ArabicGames 0.5.12 — تثبيت الحوار والبطاقات

- منع تكرار الجملة المسجلة عندما يتبدل اسم معروف بحرف OCR واحد أو يختفي الاسم، مع بقاء الرد الجديد والمتحدث الآخر مستقلين. لا تخمين لاسم جملة جديدة.
- استبعاد أزرار PHOTO STUDIO/SELECT وRESTORE المشوهة من بطاقة هدف المهمة قبل المحرك؛ حفظ أهداف مثل Find Jason وRestore power.
- خيار تفعيل المنطقة واضح أعلى البطاقة، وحفظ فوري عند تعطيلها، وحالة موقوفة صريحة. يسجل السجل الانتقالات enabled/disabled.
- إبقاء العربية المقروءة لرسالة الجوال أثناء استكمال قراءة الرسالة نفسها، ثم إتاحة مساحة للنص المكتمل. لا تنقل العربية إلى رسالة مختلفة أو موضع جديد. أضيفت أسماء جهات اتصال ظهرت في الفيديو دون طلب ترجمة.
- سجل restored منفصل عن ترجمة جديدة، دون إعادة استخدام قياس محرك قديم. السجل السابق يكرر قياس المحرك عند إعادة عرض جملة؛ هذه ليست طلبات HTTP مستقلة بالضرورة.

## التثبيت

فك ملف Update كاملًا، وأغلق البرنامج، وشغّل Reading-Fix.cmd ثم افتحه. الإعدادات والمفاتيح والنماذج محفوظة، ولا تحتاج Full Install إن كانت النسخة السابقة تعمل.

هذا إصلاح Windows فقط. تطبيق الجوال0.5.0 والشاشة0.4.9 من التحديث السابق متوافقان ولا يلزم إعادة تنزيلهما.

الفحص من سجل0.5.11 والفيديو واختبارات استنساخ. زمن انتظار طابور الحوار المسجل0ms؛ أبطأ مثال واضح استغرق2172ms في مسار المحرك. تغيير FPS لا يضمن تقليل زمن شبكة/خدمة DeepL. ظهرت QuotaExceeded، وهو رمز يجمع حد الطلبات والحصة؛ اختبر المحرك لمعرفة حالة حسابك، ولا يُفترض نفاد الرصيد من هذا السجل وحده. لا ادعاء بتجربة كونسول فيزيائية أو حل DVR.
