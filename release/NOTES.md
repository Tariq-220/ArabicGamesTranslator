# Windows 0.4.32 — استجابة الواجهة أثناء استمرار QuickMT

- السلوك المبلغ عنه هو استمرار الترجمة مع تجمد نافذة التحكم. كانت النافذة تعيد بناء حالة الاتصال وتفحص واجهات الشبكة عند كل إشعار، بما فيه كل إطار فيديو.
- تجاهل إشعار LastFrame في لوحة الحالة، وتجميع بقية إشعارات العرض إلى أربع مرات بالثانية كحد أقصى بأولوية خلفية، لإبقاء إدخال المستخدم متاحًا.
- نقل فحص عنوان الشبكة خارج خيط الواجهة، وحصره مرة كل خمس ثوانٍ كحد أقصى مع منع الفحوص المتزامنة. إيقاف المؤقت عند إغلاق النافذة.
- لا تعديل على سرعة أخذ الإطارات أو قراءة النص أو محركات الترجمة أو حزم التصحيح. أزرار الاختبار تبقى بالأعلى ومربع القوائم باقٍ.

الاختبارات الآلية لا تعادل إعادة إنتاج التعليق على جهاز المستخدم. الإصلاح يعالج مسارًا محددًا لحجز الواجهة، وتحتاج النتيجة تأكيدًا بالتجربة.

- من سجل 0.4.30: استبعاد أزرار الخريطة SET DI / REMOVE 01 من مسار الحوار فقط، واستبعاد مجموعة عناوين إحصاءات السيارة عند وجود ثلاثة عناوين منها معًا. تبقى الكلمة المنفردة مثل Speed، ومربع القائمة المستقل لا يطبق هذا المرشح. اختبارات جديدة تضمن بقاء الحوار مع تلك التسميات. لا يُدعى تصحيح كل قراءة OCR مشوهة.
