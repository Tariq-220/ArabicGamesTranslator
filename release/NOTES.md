# ArabicGames 0.5.0 — نسخة إعادة البناء من 0.4.24

دفعة الويندوز وشاشة Android / Google TV. تطبيق الجوال مؤجل للمرحلة التالية. هذه نسخة مرشحة للتجربة قبل النشر العام.

## الملفات
- **Windows-0.5.0-Full-Install.zip**: التثبيت الكامل لأول مرة. فك الضغط وشغّل Install.cmd.
- **Windows-0.5.0-Update.zip**: تحديث النسخة الحالية مع إبقاء المكتبات والنماذج والمفاتيح. فك الضغط وشغّل Reading-Fix.cmd.
- **TV-0.4.0.apk**: تطبيق التلفزيون، بنفس معرّف التطبيق والتوقيع السابق، versionCode28.
- **Source-0.5.0.zip**: المصدر المقابل.
- **Arabic-Guide.zip**: دليل عربي محلي مع صور الواجهة.

## التغييرات
- قراءة الحوار مستقلة عن القوائم ورسائل الجوال وأهداف المهمة، مع محرر معاينة حي باللمس والماوس لمربعات المصدر والظهور والخط والخلفية والمدة.
- بث Xbox داخل التطبيق مع حساب Microsoft الرسمي، واستمرار نافذته عند الانتقال للإعدادات، وخيار نافذة خارجية. دعم PS5 المباشر والخارجي باقٍ.
- منع تجمد الواجهة بسبب المحرك أو تراكم إطارات المعاينة، وضبط استقرار المصدر وتوقيت العرض ومنع إعادة عرض الشظايا والمخرجات الإنجليزية غير المترجمة.
- DeepL: عزل سياق الحوار عن القوائم، حفظ مؤقت دائم حسب اللعبة ووضع المحرك، تعافٍ أقصر بعد503، واحترام429/Retry-After. اختبارات محاكاة الخدمة لا تعني تجربة حساب DeepL حي.
- QuickMT: تحميل النموذج عبر مسارات Windows العربية، وإعادة فتح الأوزان الموجودة دون اشتراط اتصال، مع اختبار CPU فعلي. جودة العامية ما زالت تعتمد على النموذج.
- الشاشة: زر إصلاح اتصال مستقل، اكتشاف المنفذ الفعلي، وإبقاء جلسة HDMI دون إعادة فتح آلي عند تغيّر HDR/CEC. عودة للعب تخفي الخيارات وOK/رجوع يظهرها.

## التشغيل
المصدر ← معاينة المناطق ← المحرك وحفظ واختبار ← ربط الشاشة واختبار وصول العربية ← بدء الترجمة. الخطوات والصور داخل الدليل والتطبيق.

إذا نقلتك الشاشة إلى تطبيق HDMI آخر، أوقف HDMI-CEC في إعدادات التلفزيون. لا نغيّر HDR آليًا. لا تتضمن النسخة كامل حوارات GTA VI، ولا تضمن تجاوز قيود تسجيل Xbox أثناء Remote Play. توافق الشاشة والكونسول الفعليان يحتاجان تجربة الجهاز.

المصدر والمراجع والتراخيص وخطة التنفيذ ونتائج الاختبارات محفوظة داخل docs/rebuild. لم تُضمّن مفاتيح API أو شهادات توقيع خاصة.
