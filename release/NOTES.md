# ArabicGames Windows 0.4.34 — حزمة كاملة مرشحة للنشر

- تتضمن إصلاحات اختيار القراءة الكاملة واستجابة الواجهة ومربعات القوائم المستقلة وأزرار الاختبار بالأعلى.
- النص العربي المختلط ببقايا إنجليزية غير معروفة يبقى ظاهرًا، وتُعلّم البقايا بعبارة [غير واضح] بدل تقديمها كترجمة صحيحة. تبقى الأسماء ووسوم المتحدث والاختصارات المعروفة، ويُحفظ الخرج الأصلي في السجل كـquality_warning / residual_english. هذا تنقية عرض وتشخيص، وليس ترجمة للكلمة المفقودة أو دليلًا على تحسن دقة النموذج. لا طلب API إضافيًا.
- رفض السلاسل الكبيرة كلها التي كان يعتبرها الفاحص اختصارات لمجرد أنها أحرف كبيرة. استمرار رفض الخرج الإنجليزي بالكامل أو التكرار التالف.
- Google TV 0.3.20: إيقاف استعلامات الرمز القديم عند HTTP 403، وإعادة الاقتران مع موافقة الجوال، ورسالة منفصلة عند رفض الكمبيوتر. التعرف على مصدر جوال اختير خطأ ككمبيوتر عند الرفض. إعادة استخدام تذكرة الاقتران لنفس المصدر وتحمّل الأخطاء المؤقتة بدل إلغاء العملية من أول خطأ.
- Android Phone 0.4.16: الموافقة الصريحة على الاقتران تصفّر حظر المحاولات القديمة لذلك الجهاز وحده، وتبقي حماية الأجهزة الأخرى. يتضمن أحدث حزمة تصحيحات مراجعة 12.

التثبيت الكامل لأول مرة يشمل بيئة التشغيل، وأوزان النماذج المحلية تُنزّل عند اختيار النموذج أول مرة. Update لتحديث النسخة الموجودة مع حفظ المفاتيح والنماذج. ملفات الشاشة منفصلة. Samsung حزمة مطور تجريبية تحتاج شهادة؛ ليست تثبيتًا عامًا مباشرًا.

النسخة مرشحة للاختبار قبل التعميم: الاختبارات الآلية والبناء لا تثبت دقة كل حوار أو إصلاح حالة الاتصال على كل شبكة. لا تغييرات في HDMI أو HDR أو CEC. لم يثبت حتى الآن سبب الرفض المحدد على جهاز المستخدم.
