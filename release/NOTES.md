ArabicGames Windows 0.4.12 — إصلاح قراءة الحوار

- استعادة خيار العربية على الكمبيوتر في صفحة مصدر اللعبة؛ كان قد اختفى عند تقسيم الواجهة إلى صفحات. العرض المحلي مطفأ افتراضيًا للتلفزيون لتجنب تغطية النص الإنجليزي أثناء التقاط الشاشة.
- استبعاد Greet/Antagonize/Rob في يمين RDR2 قبل اختيار كتلة الحوار؛ لا تُحذف الجمل الحقيقية التي تحتوي الكلمات نفسها.
- استعادة منطقة قراءة الحوار مرة واحدة، مع زر إصلاح واضح دون حذف مفاتيح API أو نماذج الترجمة.
- حزمة إصلاح صغيرة تستنسخ النسخة الموجودة محليًا وتستبدل ملفات البرنامج المطلوبة، بدل إعادة تنزيل الحزمة الكاملة. تتحقق من البصمات وتبقي النسخة السابقة.

الإصلاح لم يُختبر على جهاز المستخدم الفعلي بعد؛ يتضمن اختبارات قراءة وواجهة وتثبيت على Windows. تجهيز تجريبي، دون نشر إصدار عام جديد.
