# ArabicGames 0.4.21 — اختبار المحرك ثابت وإصلاح HDMI

- Windows: زر اختبار المحرك وزر اختبار الشاشة وبدء الترجمة ثابتة في جميع التبويبات. آخر نتيجة اختبار تبقى في شريط الحالة عند التمرير ولا تُمحى بتحديث اتصال الشاشة.
- وضع الحوار يعرض العربية بالأسفل، ووضع القوائم ورسائل اللعبة يطلب وضعها قرب مربع النص المقروء. قد يحتوي المربع عدة عناصر؛ ليست محاذاة مستقلة لكل كلمة.
- Google TV 0.3.9: استعادة HDMI عند استمرار فقدان الإشارة لأربع ثوانٍ، بمحاولتين محدودتين لمنع إعادة التهيئة المتكررة. زر إصلاح الصورة يدويًا، وإعداد موضع القوائم/الحوار.
- يلزم اختبار انتقال اللعبة إلى رئيسية Xbox على TCL الفعلية؛ الاختبارات هنا محاكاة لتغير الإشارة وليست ضمان توافق HDR/VRR لكل شاشة.
- الجوال 0.4.12: شريط حالة واختبار ظاهر، وإعادة استخدام ملفات QuickMT الصحيحة دون إعادة طلب الحزمة.
- LG 1.0.8 دون تغيير، وSamsung 0.1.0 حزمة مطوّر تحتاج شهادة خاصة بالشاشة.
