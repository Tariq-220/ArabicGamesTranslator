# مراجعة أمان ArabicGames — حزم التجربة غير المنشورة

هذه مراجعة محدودة للمصدر والحزم واختبارات آلية؛ ليست اختبار اختراق مستقلًا ولا ضمانًا بعدم وجود ثغرات. لا تشمل اختبار الأجهزة الفعلية أو مراجعة كل سطر في المكتبات التابعة.

## ما تغير

- قاعدة Windows Firewall أصبحت للشبكة الخاصة والمصادر داخل الشبكة المحلية، بدل السماح على جميع أنواع الشبكات. لا تحذف قواعد تخص برامج أخرى.
- خادم Windows يرفض مصادر الاتصال العامة وHost غير المحلي وOrigin صفحات الويب العامة المعتاد. حد الاتصالات 32، وحد رؤوس الطلب 16KB ومهلة قراءتها خمس ثوان.
- حزم Android الجديدة تُبنى في Release دون debuggable أو jniDebuggable. النسخ الاحتياطي للتطبيق معطل؛ الشاشات الداخلية والخدمة غير مصدرة للتطبيقات الأخرى.
- أيقونة جديدة أصلية بدل أيقونة المشروع الموروثة. فُصلت عملية تجهيز الحزم عن نشرها: بناء الحزم لا ينشئ إصدارًا عامًا؛ النشر يحتاج تفعيل خيار publish يدويًا.
- إجراءات GitHub الأساسية مثبتة إلى commit SHA بدل الاعتماد على وسم متحرك فقط. التحديثات الواردة تتحقق من المستودع والاسم والحجم وSHA-256 وتفحص استخراج ZIP؛ لا يُحمّل تحديث أثناء اللعب.
- إغلاق النسخ القديمة من برنامج Windows يقتصر على نفس الملف أو مجلد التثبيت المدار للتطبيق، بدل إنهاء أي برنامج يحمل الاسم نفسه.

## ما تحققنا منه

- مفاتيح Windows مخزنة بتشفير DPAPI لمستخدم Windows نفسه؛ مفاتيح Android بتشفير AES-GCM ومفتاح Android Keystore. لا تُرسل المفاتيح للشاشة أو سجل المقارنة.
- طلبات المحركات السحابية تستخدم HTTPS ولا يوجد تجاوز لفحص شهادة TLS في كود الخدمات الذي روجع. عميل Android يمنع تحويلات HTTP لطلبات المفتاح.
- سجل المقارنة يسجل النص والمحرك والأوقات محليًا باختيار المستخدم، ولا يُرفع تلقائيًا. عند مشاركة السجل راجع محتواه؛ قد يحتوي نصًا قرأته من الشاشة.
- خادم الجوال يطلب رمز جلسة ويحد محاولات الرمز وعدد المستقبِلات. خادم النماذج المحلي يطلب Bearer عشوائيًا ويمنع Origin المتصفح ويقيد حجم الطلب وعناوين الاستماع. النماذج مثبتة بمراجعات محددة، وJisr لا يشغل trust_remote_code.
- فحص أنماط مفاتيح Google/OpenAI/GitHub وPEM للمصدر لم يجد مفاتيح مستخدم فعلية. PEM المتطابقة في LegacyPemKeyTests.cs عينات اختبار موروثة، وليست مفاتيح التطبيق أو الناشر. الفحص بالأنماط وحده لا يثبت غياب كل الأسرار الممكنة.
- استعلام OSV لأربع إصدارات أساسية (NanoHTTPD 2.3.1 وZXing 3.5.3 وSSH.NET 2026.0.0 وWebView2 1.0.3537.50) لم يرجع ثغرات مسجلة وقت الفحص؛ هذا ليس فحصًا شاملًا. مسار بناء Windows يفحص أيضًا اعتماديات NuGet الانتقالية ويحظر النتائج High/Critical.

## حدود مهمة قبل النشر العام

- استقبال Windows والشاشات المتوافقة يستخدم HTTP على شبكة محلية موثوقة، دون هوية مستقلة لكل مستقبِل. يستطيع جهاز محلي موثوق على الشبكة قراءة النصوص؛ فحص Origin ليس بديلًا عن المصادقة أو TLS، وOrigin المعتم لبعض تطبيقات TV مسموح للتوافق. لا تعرض المنفذ على الإنترنت أو شبكة عامة. خدمة الربط لا تقدم تحكمًا بالكمبيوتر أو تنزيل ملفات المستخدم.
- عند اختيار محرك سحابي يرسل التطبيق النص المقروء وسياق الحوار إلى ذلك المزود. اختيار التقاط شاشة الكمبيوتر كاملة قد يقرأ إشعارات أو نوافذ أخرى؛ الأفضل اختيار نافذة اللعبة.
- ملف Windows غير موقع حاليًا بشهادة Authenticode تجارية. SHA-256 يحمي سلامة التنزيل وفق مصدر GitHub، لكنه ليس شهادة سمعة للناشر ولا يحمي من اختراق حساب المستودع. يجب حماية حساب الناشر بالمصادقة الثنائية.
- حزم Android تستعمل شهادة التوقيع المحلية الحالية للحفاظ على التحديث فوق نسخ التجربة. مفتاح التوقيع غير موجود في المصدر أو الحزم، واسم الشهادة الحالي تجريبي. قبل توزيع واسع يجب أن يملك الناشر نسخة احتياطية آمنة لمفتاحه وخطة استمرارية التوقيع؛ تغيير المفتاح قد يمنع تحديث النسخ المثبتة.
- لا تنشر مفاتيح API أو keystore أو secure.dat أو local-token.txt أو سجلات المستخدمين. حزم التجربة ليست مدرجة تلقائيًا على Google Play أو App Store، ولم نجتز اختبار أجهزة/اختراق خارجي.

الإصدار الجديد يجهّز للمراجعة فقط. آخر إصدار عام سابق لا يتغير بمجرد بناء هذه الحزم.
