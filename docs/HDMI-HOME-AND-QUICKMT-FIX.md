# TV 0.3.6 / Phone 0.4.8

زر Home يخرج إلى واجهة النظام؛ لا نعترضه ولا نُبقي التطبيق فوق الصفحة الرئيسية. الإصلاح يحرر جلسة HDMI عند إيقاف النشاط ثم يعيد فتح المدخل نفسه عند العودة إلى المترجم. يبقى معرّف المدخل محفوظًا إذا تأخر النظام في توفير القائمة؛ تُراقب إضافات المداخل وتحديثاتها، مع إعادة محاولة محدودة وقائمة لا تتكرر. تبقى لوحة التطبيق الصغيرة قابلة للتحكم بعد الرجوع. لا يغير التطبيق إلى HDMI آخر تلقائيًا.

QuickMT المحلي: كانت قراءة الفيديو تتوقف طوال انتظار الترجمة. الآن يسمح طابور محدود باستدلال واحد وطلب انتظار واحد يستبدل بأحدث جملة ثابتة؛ تُسقط نتائج تجاوزتها جملة أحدث. يُخفّض تكرار OCR أثناء العمل المحلي لتقليل منافسة QuickMT على المعالج. لا تغيير للأوزان أو دقة الأرقام أو تعليمات النموذج. ينطبق المسار كذلك على جسر وML Kit.

هذه التعديلات تعالج الانتظار وتراكم الطلبات؛ لا تثبت أن استدلال QuickMT نفسه صار أسرع على Vivo. السجل يفصل inference_ms وqueue_ms للسطور المعروضة، ويصدر آخر قياس حتى إذا سقطت النتيجة القديمة. من الجوال: السجل ← تصدير سجل المقارنة مع الأوقات ← comparison-phone.jsonl. لا تُصدّر مفاتيح API أو رمز الربط.

التصحيحات اللغوية الجديدة تُراجع بعد استلام السجل، ولا تُعتمد المخرجات الآلية بوصفها صحيحة. يُحدّث ملف المجتمع بعد مراجعة الإنجليزية والسياق ويصل للتطبيق دون إعادة تنزيل أوزان النموذج.

اختبارات TvInputManager/TvView تحاكي Home/Return وPause بدون Stop وتأخر المداخل بعد إعادة الإنشاء. لا تستبدل الاختبار على TCL فعلية. Windows لا يحتاج تحديثًا لهذه الحزمة؛ يمكن تحديث الجوال والشاشة من صفحة التحديثات.
