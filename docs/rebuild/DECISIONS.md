# قرارات إعادة البناء

1. الأساس 0.4.24 في worktree مستقل؛ لا خلط عشوائي بتعديلات الإصدارات اللاحقة.
2. تثبيت مراجع المصادر وقراءتها مرة واحدة قبل تحديد طريقة النقل؛ لا اعتبار وصف الإصدار أو لقطة شاشة إثباتًا للتنفيذ أو لتغطية جميع حوارات اللعبة.
3. قبول الترجمة يُقاس على مدخلات متطابقة، ولا يُستنتج من نجاح البناء أو أسماء النماذج.
4. نموذج الهاتف مؤجل بطلب المستخدم؛ الناتج النهائي في هذه الدورة Windows وAndroid TV.
