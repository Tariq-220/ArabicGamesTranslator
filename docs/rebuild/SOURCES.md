# سجل المصادر (تُستكمل الأدلة قبل قرارات النقل)

| المصدر | الرابط | الحالة |
|---|---|---|
| VI Desktop | https://github.com/vi-translator/vi-translator-desktop | تحقق المستودع، AGPL-3.0، main، الفحص التفصيلي قادم |
| Sefflex GameTranslator | https://gitlab.com/sefflex/GameTranslator/-/releases | تثبيت نسخة المصدر والإصدار قادم |
| Nino | https://github.com/yunusdemirbag/nino-game-translator | تحقق المستودع، AGPL-3.0، main، الفحص التفصيلي قادم |

الصور المرجعية في المحادثة تعرض طبقات رسائل جوال اللعبة، القوائم والمساعدة والخريطة. لا تثبت وحدها محرك الترجمة أو وجود جميع ملفات الحوار. إثبات ذلك من الكود والبيانات والتراخيص مطلوب.
