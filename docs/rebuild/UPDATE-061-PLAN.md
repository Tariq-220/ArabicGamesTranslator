- أضيفت حواجز هدف المهمة ووصف الخريطة وترتيب تنقل الخريطة المقلوب داخل الجوال؛ 22 استنساخًا جديدًا نجحت. منع أثر OCR المتكرر قبل المحرك، وتنظيف بادئات OCR المحدودة قبل الأسماء المعروفة دون اختراع أسماء جديدة.
