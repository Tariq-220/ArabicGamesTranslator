# إصلاحات ما بعد 0.5.12 — تقدم محفوظ

آخر توجيه: لا تغيير للموديل أو المحرك. الأولوية للتأخير وتكرار لوسيا، واستقرار الجوال، وعدم تعطيل وصف الخريطة. لا تعديل لإحداثيات المستخدم أو مفاتيحه أو جودة النموذج. لا APK جديد بلا تعديل للمستقبل.

## نُفذ في المصدر، ولم تُجهز حزمة جديدة بعد

- التقاط Windows.Graphics.Capture للنافذة/الشاشة المحددة، مع أحدث صورة فقط وبديل GDI عند عدم الدعم. نفس المسار العام المستخدم في VI، بتطبيق C# مستقل يعتمد واجهات Microsoft الموثقة. لا مكتبة أو تنزيل نموذج جديد.
- الفاصل الزمني يشمل وقت الالتقاط بدل إضافته بعد العمل. لا تغيير لقيمة FPS المحفوظة.
- القراءة تتبع مواعيد دورية تراكمية؛ فرق 1ms بين فريمات معدل واحد لا يخفض OCR إلى نصف المعدل. لا طابور صور أو دفعة تعويض بعد توقف طويل.
- قناة البطاقات السحابية المستقلة تسمح بدفعة حتى 4 أجزاء بدل طلب متسلسل لكل جزء. الجوال يظل جزءًا واحدًا حسب سياسة عرضه، والمحركات المحلية/ذات fallback مشترك تظل قابلة لمقاطعة البطاقات بين الأجزاء.
- قياس منفصل لأول إطار OCR مطابق حتى الإرسال، ووقت ما قبل الطلب وانتظار خط الحوار وزمن/طريقة الالتقاط. TotalMs القديم محفوظ لمعنى المقارنات السابقة؛ لا قياس مزعوم لزمن HDMI أو رسم التلفزيون.
- بادئة OCR المسجلة L Lucia تُرد إلى Lucia قبل مقارنة الحوار. اختبار يعيد قراءتي ofus/of'us الفعليتين في خط الحوار.
- إزالة تكرار كامل طويل داخل نتيجة عربية واحدة، بحماية تكرار المصدر المقصود والردود والأرقام والنفي. لا إعادة صياغة عامة ولا تغيير موديل.
- رفض لوحات الخريطة كجوال عند وجود حقلين مميزين كاملين (مثل SELL VALUE/REGISTRATION FEE)، حتى لو خرج رأس MAP من القص. رسائل الملاحة الفعلية لا تُمنع.
- إذا رفض المحرك دفعة خريطة، تُطلب أجزاؤها منفردة بدل إسقاط الوصف مع العنوان المرفوض. الأجزاء المقبولة تُعرض؛ حالة الفشل الجزئي واضحة ولا تظل «قيد المعالجة» بعد انتهاء الطلب.
- رسالة OutputRejected العامة توضّح أنها لآخر نص في قناة الحوار، وليست حكمًا على بطاقة الخريطة أو كل المحرك.

## التحقق

- محليًا: 227 اختبار Core محدد نجحت (الحوار والتثبيت والبطاقات والقياس و061/062/063). لا يُدّعى نجاح كامل كل المستودع.
- Translation.Tests غير مستعادة محليًا؛ `dotnet test --no-restore` لم ينفذ اختبارات هذا المشروع. التحقق الفعلي لها مطلوب على Windows CI.
- أضيف اختبار Windows أصلي يلتقط نافذة WPF تتغير من الأحمر إلى الأزرق، ثم يتحقق من GDI. يسجّل عدم دعم WGC صراحة ولا يعتبر GDI دليلًا على نجاح WGC.
- بانتظار تجميع Windows، الاختبارات واختبار الالتقاط الأصلي قبل أي حزمة.
- فحص Windows الأول 46133529451 توقف عند خطأ نطاق متغير في نص القياس بالواجهة. واجهات WGC تجمعت؛ تم إصلاح خطأ الواجهة والتحذير، ولم يُبنَ أو يُرسل مثبت من هذا الفحص.

## حدود الإثبات والمتابعة

لا وعد بانعدام التأخير أو حل كل قراءة من تعديل الفاصل وحده. قياسات المستخدم السابقة ناقصة قبل تثبيت النص؛ لا قياس سابق لزمن PrintWindow. بعد نجاح Windows يُراجع الالتقاط والتوقيت ثم تُجهز حزمة واحدة خاصة، دون نشر عام. رقم النسخة ما زال 0.5.12 حتى تجهيز الحزمة.
