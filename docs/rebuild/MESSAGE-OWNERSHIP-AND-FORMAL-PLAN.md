# إصلاح ثبات الرسائل والفصحى — 0.5.8

طلبات المستخدم: حوار فصيح دون حجب أو إسقاط، خط حوار ثابت، جوال ثابت عند نقص OCR، منع تكرار التنبيهات وظهورها في مربعين، وإيقاف القوائم مؤقتًا إن كانت مصدر أرقام المسافة. السجل الإضافي متوقع ولم يصل بعد؛ لا يتوقف فحص المقطع عليه.

الدليل: Snapchat-1734858182.mp4 مدته4.9ث؛ تختفي الرسالة الأولى وتعود مع ثبات بقية الصفحة. صورتان تظهران التنبيه نفسه كصورة بطاقة عريضة ونص طويل ضيق من قناة أخرى.

1. تجاوز نصوص الحزمة والكاش ذات العامية غير المحسومة إلى المحرك المختار؛ لا منع لنتيجة عربية من المحرك بسبب أسلوبها. تطبيع المفردات الواضحة فقط، دون تغيير كلمات نفي ملتبسة.
2. توحيد ملكية نص الجوال والتنبيه وإبعادهما عن الحوار بعد التأكد النصي والمكاني. اعتماد حجم البطاقة المؤكدة، وعدم نشر أنصاف بطاقة التنبيه.
3. الاحتفاظ بالنص الكامل عندما يعيد OCR مقدمة أو نهاية قصيرة منه، وعدم اشتراط تكرار جميع أسطر صفحة جديدة حرفيًا. تثبيت أبعاد الصفحة المؤكدة، ونشر محادثة متناسقة عند جاهزية أجسام رسائلها.
4. إيقاف مطابقة حجم الحوار مع ارتفاع OCR مرة واحدة، مع حفظ الخط والحجم والمواضع. إيقاف بطاقتي القوائم ووصف الخريطة مؤقتًا مع حفظهما وإمكان تفعيلهما لاحقًا.
5. اختبارات محلية ثم Windows CI وصور وAndroid CI. لا بناء تثبيت لكل تعديل. الحزمة النهائية مرة واحدة بعد التحقق. نسخة الجوال مؤجلة وفق اختيار المستخدم السابق.

مساحة العمل امتلأت بعد تنزيل المقطع؛ حُذفت صورتا معاينة PNG مولدتان من الفحص السابق فقط. بقيت كل المقاطع والملفات الأصلية.

مثال عامية مؤكدة من نص جاهز (TranslationMs=null وOrigin=0): «كل هذا عشان فيديو؟» للمصدر Stranger:Damn,man,chill!...؛ تجاوز ذاكرة العامية ضروري كي لا يعيد تشغيل المهمة نفس النص. بعض رصد«مو» اسم شخص في المصدر، ويجب حمايته.
أُزيل اختبار50%القديم للنشر لصالح صفحة متناسقة الأجسام، مع بقاء الترجمة قيد العمل خارج خيط الواجهة وأولوية الحوار. قد تنتظر الصفحة الأولى اكتمال رسائلها بدل القفز بين أنصافها.
