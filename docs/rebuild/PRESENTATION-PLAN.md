## متطلبات الصور الجديدة
- [ ] الحوار: خط مثل VI (Noto Sans Arabic / Tajawal وخيارات الخطوط المرخصة)، وزن/حجم/محاذاة/ظل واضح، خلفية بحجم النص لا بعرض الشاشة، بدون خلفية أو مربع مستطيل/مستدير/نمط اللعبة. الموضع مستقل، يغطي الإنجليزي أو يعلوه/يليه. أسماء الشخصيات وألوانها مستقلة عن متن الحوار.
- [ ] رسائل جوال اللعبة: إعادة عرض اللوحة بجانب الجوال كاملة بتخطيطها، رأس المحادثة والرسائل الصادرة/الواردة وألوانها، وخلايا النصوص بمواقعها، لا فقرة كبيرة مجمّعة. الحفاظ على الفصل بين المحادثات. حجم خط يلائم الخلية ولا يتجاوزها.
- [ ] القوائم/الإشعارات/الأهداف: خلايا بمواقعها وبنية النص، أحجام وحدود ومدة مستقلة؛ لا إزاحة الحوار أو جمع كل النص في وسط الشاشة.
- [ ] مناطق القراءة مثل VI: إضافة/حذف/تفعيل، مربعا مصدر وظهور ظاهران معًا بألوان مختلفة، تحريك ومقابض زوايا، إدخال يسار/أعلى/عرض/ارتفاع بالنسبة، محاذاة وموضع العرض، معاينة نص تجريبي حية، حفظ/استيراد/تصدير التخطيط للمشاركة.
- [ ] خيارات عرض VI: الخط، الخلفية، مطابقة الحجم، محاذاة أفقية/رأسية، وضع فوق/تحت/تغطية/مخصص، التدرج والعتامة، تمييز لون الاسم؛ توضيح الخيارات المؤثرة على الجودة/السرعة دون إخفاء الخيارات.
- [ ] ترتيب واجهة البرنامج: معاينة واسعة وإعدادات قابلة للتمرير بجانبها، مجموعات واضحة، البدء/الحالة/الاختبار ثابتة، إعدادات النموذج لا تتغير عند تعديل المظهر.
- [ ] وضع أسرع اختياري: تقليل انتظار الاستقرار والعرض باعتدال مع حفظ الوضع المتوازن، لا زيادة تراكم الطلبات ولا مساس سياق DeepL أو إظهار الإنجليزية.
- [ ] الشاشة: لوحة عائمة مختصرة مثل Sefflex باللغة العربية، حالة HDMI/الاتصال/آخر ترجمة، تعليمات أزرار الريموت، إخفاء/إظهار، تحريك الترجمة، اختبار، إصلاح الاتصال وإصلاح الصورة منفصلان؛ لا إعادة ضبط HDMI/CEC/HDR الناجح.
- [ ] تطابق تنسيق Windows وGoogle TV؛ حفظ توافق SSE والإعدادات القديمة، التوقيع والتحديث، لا نشر عام تلقائي.

## مراحل مترابطة
1. قراءة ملفات VI ذات الصلة من النسخة المثبتة فقط، وتوثيق الفرق بين النقل الهندسي وإمكان مطابقة صور بكسلًا ببكسل.
2. نموذج تنسيق مشترك + خلايا نص ذات إحداثيات + فصل قراءة/ترجمة/عرض، مع اختبارات النصوص والحفظ والتوافق.
3. عارضا Windows/TV ومحرر مناطق ورقمي ومشاركة التخطيط، ومعاينات فعلية للحوار والهاتف والقوائم.
4. لوحة TV العربية + وضع السرعة، اختبارات التراجع/المناطق/الواجهة/الربط.
5. بعد مرور الاختبارات، بناء دفعة نهائية واحدة Windows/TV وإرفاق مسودة للتجربة.
