# تجربة Arabic Game Localization V4

طلب المستخدم تجربة المشروع لمعرفة فائدته لترجمة ArabicGames الحالية. المصدر: https://github.com/axxx503/Arabic-localization-game/releases/tag/V4.0

## ما جرى اختباره

- حزمة V4.0 المنشورة: 29561 بايت، SHA256 `7588220c11fee3747b507ed6ff67aa96f021c37ed2e1c51cdb44a9912f57df3c`.
- قرأت أداة `coverage_validator.py` كاملة قبل تشغيلها؛ تعمل بمكتبات Python القياسية وتقرأ JSON فقط. استُخدمت دون تعديل في مساحة منفصلة، ولم يُفعّل SKILL.md أو تتبع تعليمات بدء مشروع تعريب جديد.
- عشرة أمثلة تشخيصية، منها ثمانية مشاكل معروفة وحالتان سليمتان. هذه أمثلة يدوية لإظهار حدود الأداة، وليست قياسًا إحصائيًا لدقة الترجمة.
- سجل تاريخي واحد، قُرئ مرة واحدة. أخذت آخر 500 زوج مصدر/ترجمة وأزلت التكرارات فبقي 447 زوجًا. لم تُرسل النصوص إلى أي خدمة، ولا نُسبت نتائج السجل القديم إلى إصدار0.5.7.

## النتيجة

- كشفت الأمثلة ذات الناتج الفارغ، والإنجليزي الكامل، واختلاف `{player}` عن `{name}`.
- لم تكشف: `هل أنت ready؟`، و`بيلي:` وحدها مقابل جملة كاملة، وترجمة `Do not shoot.` إلى `أطلق النار.`، وعلامات الاستفهام وحدها، والأسلوب العامي. بقيت الحالتان السليمتان بلا إنذار.
- على السجل التاريخي: 64 خانة فارغة، و7 خانات بلا حروف عربية وفق تعريف الأداة، وصفر اختلاف للمتغيرات. الخانات الفارغة قد تشمل أحداث رفض أو تخطي مقصودة؛ لا تكفي هذه الأعداد لإثبات أخطاء ترجمة أو سببها.
- أداة التدقيق لا تعيد الترجمة ولا تصحح المعنى، ولا تقيس OCR أو التأخير أو استقرار العرض. المقارنة النصية أظهرت أن توجيهات الفصحى الطبيعية والمعنى السياقي وعدم إسقاط المعلومات وحفظ النفي والأرقام موجودة أصلًا في AiTranslator وArabicRegister؛ نسخ التوجيهات وحده ليس دليل تحسن.

## القرار

يفيد المشروع كمرجع لتدقيق حزم ترجمة ملفات الألعاب وتوثيق المصدر والسياق ومعجم المصطلحات. فائدته المباشرة لترجمة الصورة الحية محدودة، ولا توجد نتيجة تثبت أنه بديل للمحرك أو يحسن السرعة والدقة بمجرد إضافته. لا يُضاف مدققه كشرط حجب جديد للحوار، ولا تُضاف معالجة قلب/تشكيل ثانية إلى WPF وAndroid اللذين يدعمان العربية أصلًا.

لم يتغير كود التطبيق أو إعداداته، ولم تُستدعَ نماذج أو خدمات مدفوعة، ولم تُبنَ نسخ تثبيت. الملخص القابل للمعالجة: `/workspace/work/upstream-review/localization-v4-trial/result.json`؛ أدوات التجربة المؤقتة في `/tmp/localization-v4-trial/`.
