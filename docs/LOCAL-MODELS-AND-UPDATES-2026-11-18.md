# نماذج الجوال، السجل والتحديثات

- الجوال 0.4.7: صفحة المحرك ← «تنزيل / إدارة QuickMT وجسر على الجوال». نزّل QuickMT (نحو 363 MB) أو جسر INT8 (نحو 55 MB للتنزيل). بعد اكتمال SHA-256 اختر «استخدام النموذج المختار». لا يحتاج API أو تشغيل اللابتوب. جسر فصحى وسعودي يشتركان في الحزمة نفسها.
- يمكن استيراد ZIP يحتوي ملفات النموذج المطابقة للحزمة المعروفة؛ التطبيق يتحقق من أسماء الملفات وأحجامها وبصماتها ويمنع مسارات الخروج والتكرار. الملف وحده لا يُشغّل محرك كمبيوتر على أندرويد؛ مكتبة التشغيل الأصلية مدمجة في APK arm64.
- يستعمل الهاتف تنفيذ Hearth لـCTranslate2، مثبتًا عند `bc6823b8ec8254eefa222d28e60d70ccdd7d67ce`؛ ملفات كل نموذج مثبتة بمراجعة وبصمة في `native-local-models.json`. أندرويد 9 أو أحدث للنماذج الأصلية. ML Kit القديم يظل خيارًا منفصلًا.
- Windows: QuickMT وجسر متاحان عبر محركه المحلي المرفق، وتبقى النماذج والمفاتيح خارج التحديث. لا ننقل مكتبة أندرويد إلى Windows.

## المقارنة الفعلية

نتائج المضيف محفوظة في `community/reports/local-model-smoke-2026-11-18.json`. أوقات المضيف تشمل تحميل النموذج في كل عملية وليست قياسًا للجوال أو اللابتوب. بعض العبارات الاصطلاحية ضعيفة في كلا النموذجين؛ لا تعني إضافة نموذج تحسنًا تلقائيًا في الدقة.

سجل الجوال يحفظ النص والمحرك وزمن القراءة والترجمة وتجهيز السطر. Windows يحفظ مقارنة JSONL. القياس لا يشمل بث الكونسول أو عرض التلفزيون. العب على HDMI واجعل Remote Play للقراءة لتفادي إضافة تأخير تحكم البث إلى اللعب.

Xbox: الجوال يقتطع منطقة الحوار قبل نقل JPEG إلى Android، ويمنع طلب إطار ثانٍ أثناء المعالجة؛ القراءة كل 200ms أثناء ظهور الجلسة. لا تُقرأ كلمات مرور Microsoft. استبعاد Greet / Antagonize / Rob محصور في تسميات التحكم عند الطرف الأيمن في RDR2؛ لا نحذف جملة حوار تحتوي الكلمة. الكمبيوتر يدعم 80ms افتراضيًا و40ms اختياريًا على حساب الحمل؛ لا يغيّر سرعة المحرك أو الشبكة.

## الإبلاغ والتصحيح

«السجل ← الإبلاغ عن خطأ لغوي» يعرض بيانات السطر قبل نسخها وفتح GitHub. يلصق المستخدم البلاغ ويرسله من حسابه؛ لا يوجد رفع خفي أو GitHub token مدمج. البلاغات المحلية غير المرسلة لا تُعد بلاغات منشورة.

اعتماد التصحيح محليًا يستخدم النص ذاته في اللعبة ذاتها قبل طلب المحرك. ينزل التطبيق حزمة التصحيحات العامة المراجعة مرة كل 12 ساعة عند فتحه، ويمكن تعطيلها من السجل. لا يرسل طلب تنزيل الحزمة اسم لعبتك أو سجل حواراتك. لا يعتمد بلاغات الجمهور أو نواتج AI مباشرة؛ يضيف المسؤول التصحيح بواسطة `scripts/review-translation-report.py` ثم يراجع تغيير الملف في GitHub. هذا قاموس مراجعة، وليس تدريبًا جديدًا للنموذج.

## التحديث الهوائي

الجوال والشاشة: «التحديثات» ثم فحص / تنزيل أو تشغيل الخيار التلقائي عند فتح التطبيق. يفحص HTTPS ومصدر المستودع وحجم الحزمة وSHA-256 واسم الحزمة ورقم الإصدار وتوقيع APK المطابق. أندرويد يتطلب إذن تثبيت التطبيق وتأكيد التحديث؛ لا يُحذف التطبيق ولا بياناته. يتوقف تنزيل تحديث التطبيق إن بدأت جلسة لعب.

Windows: فحص وتنزيل تلقائي خارج اللعب، مع خيار تعطيله؛ التثبيت وإعادة التشغيل بزر. كل منصة لها ملف مستقل في GitHub Releases، والنماذج تُنزّل عند الحاجة فقط. النسخ القديمة التي تسبق صفحة التحديثات تحتاج تثبيت هذا التحديث مرة واحدة.

## حدود الفحص

بناء المكتبات واختبارات البروتوكول والتشفير والتحقق لا تستبدل تجربة Sony / PS5 وTCL وVivo حقيقية. يحتاج الاقتران المباشر تجربة الجهاز ورمز الربط لدى المستخدم. لا نَعِد بانعدام التأخير أو دقة كاملة.

## اختبار API من الجوال

افتح محرك الترجمة، اختر DeepL أو غيره، الصق المفتاح ثم «حفظ واختبار API». يرسل عبارة قصيرة ويعرض زمن الطلب وردًا عربيًا أو رقم HTTP. المفتاح الفارغ يحتفظ بالمحفوظ، ويمكن ترقية مفتاح الجلسة المؤقت إلى حفظ دائم بزر الحفظ. لا يعني نجاح الاختبار أن ترجمات الحوار دقيقة، ولا يشمل الوقت قراءة الفيديو أو عرض الشاشة.

المفاتيح تُحفظ AES-GCM داخل التطبيق عبر Android KeyStore، ويجري التحقق من فك تشفير القيمة قبل اعتمادها. إذا فشل التخزين يعرض الاختبار أنه مؤقت، ولا يدعي أن المفتاح حُفظ. الاختبار الفعلي على KeyStore في جهاز المستخدم يظل مطلوبًا؛ اختبارات الحفظ المعزولة تتحقق من التشفير وإعادة القراءة وتبديل المحرك.

DeepL: «تلقائي» الأكثر توافقًا. «أسرع (latency)» يُرسل طلب المحرك السريع إذا كانت الخدمة تدعمه؛ HTTP 400 يعني أن اللغة أو الباقة قد لا تدعمه، فاختر تلقائي. خيار السياق المختصر يستخدم السطر السابق فقط، وقد يقل فهم الحوار. لا نعد بأن تفعيل الخيار يسرّع الخدمة.

كانت أخطاء اتصال الجوال جميعها تفرض انتظار 15 ثانية. الآن تبدأ أخطاء الشبكة العابرة بنحو 1–1.5 ثانية وتتدرج عند تكرار الفشل، بينما أخطاء الحصة لها مهلة مستقلة وتحترم Retry-After. لا تُعرض ردود الخدمة الخام أو المفاتيح في السجل.
